# Yiiframework v19 acceptance

## Source decision

Debian Trixie does not package the Yii framework. The appliance installs the
official Yii 2.0.55 advanced-application release archive, verifies SHA-256
`e4e74986791b14deb0175685e9c45ebf0809984ae9dd19d284142fb06cbb348a`,
and records signed tag commit `babee66def599432735a1ed39c9cf0bc5163a775`.
Yii 2 remains supported and works with PHP 8; the current application template
requires PHP 8.2 or later. PHP, Apache, MariaDB, and extensions come from
Debian Trixie.

## README crosswalk

| Contract | Focused acceptance | Required result |
| --- | --- | --- |
| Yii sample | Request the customized frontend over HTTP and HTTPS, plus the backend over HTTPS | The frontend renders the TurnKey Yii sample; the protected backend renders its login form with a CSRF token |
| Database connectivity | Find the seeded verification-token migration through the Yii database component and directly through MariaDB | Both paths return exactly one row |
| Console tooling | Run Yii help and migration history from the system path | The console starts and reports the applied migration |
| Web server | Require active Apache, a valid configuration, and live PHP requests | Apache serves both application entry points |
| Source integrity | Compare runtime version and retained provenance with the pinned release | Yii 2.0.55 and the exact archive digest are recorded |
| Supervised updates | Run `yii-update --check` | The latest official Yii 2 tag, commit, and advanced-app asset are reported |
| Inherited administration | Cite unchanged SSH, Webmin, Adminer, Postfix, and common platform behavior | Core 19 PASS run `20260824t010251z-1634-32241` at source `24c82ee3540ce545422742b0e28ba6b687c53ec2` remains applicable |

## Deferred issues

- The sample retains Yii's advanced frontend and backend structure. Creating
  a product-specific administrator workflow would change this framework
  appliance's purpose.
- Updates remain supervised because replacing the application template can
  overwrite local application code and configuration.
- Docker acceptance does not repeat installer, kernel, or hardware checks.
